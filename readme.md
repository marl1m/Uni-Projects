# Uni-Projects

This repository contains a collection of university assignments focused on Data Science and Machine Learning. All projects are implemented primarily in Python using standard libraries and frameworks such as Pandas, NumPy, Scikit-learn, and others.

## Projects

### 📌 Supervised-Learning-Project
A project exploring classification/regression using supervised ML techniques. Includes data preprocessing, model training, evaluation, and result interpretation.

### 🧠 Unsupervised-Learning-Project
Covers clustering, dimensionality reduction, and pattern discovery using unsupervised methods such as K-Means and PCA.

### 🗂 Text-Mining-Project
Focuses on natural language processing tasks like text preprocessing, TF-IDF, topic modeling, and sentiment analysis.

## Requirements

- Python 3.8+
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
